# 4. Remove the unused LiveKit packages

Date: 2026-10-03
Status: Accepted

## Context

`livekit-client` and `@livekit/components-react` were installed for a future
audio connection, but no code imports them. The product spec chooses Pipecat
for the audio pipeline (spec decision 17), so they may never be used.

Unused dependencies still cost something:
- Readers of `package.json` assume the app uses LiveKit.
- Security alerts can fire for vulnerabilities in code the app never runs.
- They add to `node_modules` and to every CI install.

They do not make the shipped app heavier: Next.js only bundles code that is
imported, so unused packages never reach the browser.

## Decision

Remove both packages with `npm uninstall` (the lockfile is regenerated by npm,
not edited by hand). The README no longer lists LiveKit.

## Consequences

- `package.json` lists only what the app uses.
- Reversible: `npm install livekit-client @livekit/components-react` restores
  them if the audio connection decision (M2/M4) ends up choosing LiveKit.
